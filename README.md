# Proyek Go - Variabel, Struct, & Function

Proyek sederhana menggunakan bahasa pemrograman **Go** yang mendemonstrasikan penggunaan:
1. **Variabel** (deklarasi `var` dan *short declaration* `:=`)
2. **Struct** (struktur data `Lingkaran`)
3. **Function / Method** (perhitungan luas lingkaran)

---

## Cara Menjalankan

Buka terminal di root folder proyek, lalu jalankan perintah berikut:

```bash
go run main.go

Berikut adalah outputnya :
